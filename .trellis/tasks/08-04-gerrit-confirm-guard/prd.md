# 写操作确认流与护栏

## Goal

为 Gerrit 写操作加专属护栏：确认框展示详情 + 浏览器打开按钮，LLM 不得自主发起。

## Requirements

- 确认框展示 change 主题/owner/改动行数
- 提供'在浏览器打开'按钮（不鼓励盲打分）
- LLM 在自由对话被诱导执行 +2 时只生成待确认不落地
- 确认超时作废
- agent 自主发起写操作的路径在代码层不可达

## Acceptance Criteria

- [ ] 诱导 agent 直接 +2，只会生成待确认动作不落地
- [ ] 确认框有浏览器打开按钮
- [ ] 超时作废

## Notes

- 盲打 +2 是真风险（要看 diff），护栏防呆
- LLM 不可自主发起是硬约束
