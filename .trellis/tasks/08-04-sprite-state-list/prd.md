# 状态与动作清单

## Goal

枚举宠物所有 sprite 状态与动作，作为素材生产的需求清单。

## Requirements

- 状态：idle/happy/focused/worried/grumpy/sleeping
- 动作：nod(Tier1)/cheer(Tier2)/special(Tier4)
- 每状态 8–12 帧规格
- 输出状态→帧数→fps→循环点的需求文档

## Acceptance Criteria

- [ ] 状态与动作覆盖 emotion-state 与 celebration 所有触发
- [ ] 每状态帧数规格明确
- [ ] 需求文档可作为生成输入

## Notes

- 对齐 emotion-state 和 celebration 的全部触发
- 这是素材生产的需求源
